# AGENTS.md

## Project context

- This project is a collection of R functions that are meant to
  streamline and improve consistency with lab coding projects.
- Informal modules involve processing and visualization of scRNA-seq
  data, chromatin data, and genbank/ApE files.
- The package is published through my R Universe repo, but widespread
  adoption is not anticipated.
- Some modules may be split off for their own packages for wider
  distribution in standard repos.

## Working practices

- Explain the existing code behavior before changing it.
- For R changes, run the relevant checks and report what you ran.
- Summarize changed files.
- Use a functional coding design, tidyverse idioms, and native pipes
  where possible.
